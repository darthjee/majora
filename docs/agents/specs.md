# Specs

A **spec** is a persistent, high-level design doc for a feature area, written
before or alongside the issues that implement it and used to guide their
creation. It is removed once the feature area is fully implemented and the
knowledge has moved into the permanent docs.

This file is the single hub for feature spec entrypoints: every feature spec
registers here only, never directly in `AGENTS.md`.
