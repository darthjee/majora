# Plan: Improv game list in home

Issue: [774-improv-game-list-in-home.md](../../issues/774-improv-game-list-in-home.md)

## Overview

Makes the games grid on `/#/`, `/#/games/`, and `/#/my-games/` adapt its
column count to the number of games actually rendered (instead of always
using a fixed 4-column layout), and changes those pages' game cards from a
square photo box to a fixed-height rectangle. Every other list type keeps
its current fixed-column, square-card behavior unchanged.

See [frontend.md](frontend.md) for the full plan.
