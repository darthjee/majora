# Split `_character_shared.py` by domain

Break `backend/games/views/game/_character_shared.py` (1,111 lines, 61 top-level functions) into 6 new domain-specific files plus a reduced core, moving each `build_*` factory verbatim (body unchanged) into the file matching its resource domain. Do not touch the ~118 external call sites yet — that's Step 3.

Move the domain-specific imports (serializer/leaf-module imports that are only used by the functions being relocated) alongside each function group; each new file also imports `_build_api_view` (and `_check_character_all_permission` where used) from the reduced `_character_shared.py`.

## Files to Change

- `backend/games/views/game/_character_shared.py` — reduce to ~120 lines, keeping only: `_build_api_view(methods, permission_class)`, `_check_character_all_permission(request, game, character_id, npc)`, `build_access_view(npc)`, `build_full_view(npc)`. Remove all domain-specific imports that become unused.
- `backend/games/views/game/_photo_shared.py` (new) — `build_photos_view`, `build_photo_upload_view`, `build_photo_detail_view`, `build_photo_deletable_view`, `build_photo_set_view`. Imports `_build_api_view` from `_character_shared.py`; photo functions from `_photo_upload.py`, `_photo_detail.py`, `_photo_deletable.py`, `_photo_set.py`.
- `backend/games/views/game/_item_shared.py` (new) — `build_items_view` (list GET + POST create, dispatching to `character_item_create` from `._item_create`), `build_item_detail_view` (GET/PATCH, PATCH dispatching to `character_item_update` from `._item_update`), `build_items_all_view`, `build_item_detail_full_view`, `build_item_photo_upload_view`, `build_items_available_view`, `build_items_available_all_view`, `build_item_acquire_view`, `build_item_acquire_all_view`, `build_item_remove_view`, `build_item_remove_all_view`. Imports `_build_api_view`, `_check_character_all_permission` from `_character_shared.py`; item functions from `_items.py`, `_item_create.py`, `_item_update.py`, `_item_exchange.py`, `_item_photo_upload.py`.
