# i18n keys

Extend `staff_user_page.yaml` in **both** `en` and `pt` (checked by `npm run check_i18n`) with the panel's keys:

```yaml
staff_user_page:
  # ...existing keys...
  recovery_tokens_title: Recovery tokens
  recovery_tokens_loading: Loading recovery tokens...
  recovery_tokens_error: Failed to load recovery tokens. Please try again.
  recovery_tokens_empty: This user has no recovery tokens.
  recovery_token_status_column: Status
  recovery_token_created_column: Created
  recovery_token_expires_column: Expires
  recovery_token_preview_column: Token preview
  recovery_token_status_used: Used
  recovery_token_status_revoked: Revoked
  recovery_token_status_expired: Expired
  recovery_token_status_valid: Valid
```

(Portuguese wording is a judgment call for whoever implements this — keep it consistent with the existing `staff_user_page.yaml` / `staff_users_page.yaml` `pt` translations' tone.)

## Files to Change

- `frontend/assets/i18n/en/staff_user_page.yaml` — add the keys above.
- `frontend/assets/i18n/pt/staff_user_page.yaml` — add the same keys, translated.
