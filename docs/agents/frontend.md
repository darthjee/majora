# Front-End Architecture

The Majora front-end is a React + Vite SPA located in `frontend/`. It runs in its own Docker
container (`majora_fe`) and is served through the Tent proxy.

This file has been split into multiple pages under `docs/agents/frontend/` to improve
readability. See the files in that folder for the full content. Each split file preserves the
original section headings.
